Step-by-Step Walkthrough

What you will see in the demo video, explained in sequence:

01
App Launch & Cinematic Intro
The app opens with a full-screen cinematic intro animation — bold text captions such as "ISOLATE DRUMS", "EXTRACT VOCALS" appear, establishing the app's core capabilities. This intro lasts approximately 10 seconds and can be skipped by tapping.
02
Main Dashboard — Premium UI
The main dashboard appears: a central analog gauge, a premium session timer (59:30 MIN), and 5 empty stem channels (VOCALS / BEAT / BASS / MELODY / DRUMS). The interface is fully functional and responsive.
03
Load Track — File Picker
The user taps "LOAD TRACK". The native iOS Files picker opens. A real audio file (MP3/WAV) is selected from the device. The track name appears in a scrolling ticker on the dashboard.
⚠ NOTE: A valid audio file must be selected. The app rejects non-audio files by design.
04
Terms & Privacy Agreement
Before processing, the app requires the user to read and accept the Terms of Service and Privacy Policy. The user scrolls through the legal agreement and taps "Accept". This is a required step — without acceptance, the AI processing does not begin.
05
AI Separation — Cloud Processing (Demucs + Roformer)
The user taps "SEPARATE 5-STEM". The gauge displays "STEM-DECONSTRUCTION // ACTIVE". The audio is securely uploaded to our serverless GPU cloud (RunPod), processed by the Demucs AI model, and the 5 separated stems are returned — typically in 30–90 seconds depending on track length.
⚡ Cloud AI is live and online during your review.
06
Playback & Mixer Controls
Once separation completes, all 5 stem channels light up with live VU meters. The user taps PLAY. Each channel (VOCALS, BEAT, BASS, MELODY, DRUMS) can be individually SOLO'd or MUTED in real-time, demonstrating the app's full interactive mixer functionality.
07
Export — All 5 Stems
The user taps "EXPORT ALL". All 5 separated stems are available for individual or bulk export in high-quality audio format, ready for use in any DAW or audio workflow.

// Notes for Apple Review Team

This application uses a cloud-based AI engine (RunPod serverless GPU) to separate audio stems. The core AI processing happens server-side and requires an active internet connection. The cloud backend is live and fully operational during your review period.

Please use a valid .mp3, .wav, or .m4a audio file when testing. Non-audio files or corrupted files are intentionally rejected by our internal validation logic. If no audio file is available on the review device, any standard music file will work.
